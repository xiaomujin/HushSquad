> 本文件是全项目**唯一**记录实测数字的地方。任何「做完了」的结论必须有对应行。
> 规则：一行一个配置；必须写 n 与测试条件；**禁止只记均值**；升级依赖后新增行，不覆盖旧行（保留趋势）。

## 重要限制（2026-11-16 起）

当前测试素材为**合成音频**（`testkit gen` 生成，随机种子固定），只能用于趋势与回归，**不能**用于：

- D6 盲听裁决（30 ms 延迟可接受性）；
- 技术设计 §11.2「降噪有明显压制」的终判；
- 「降噪不引入明显失真 / 不吞字」这类主观判断。

真实素材到位后的顺序：替换 `testdata/` → 重跑 P3-5 基线 → 才允许做 P3-6。

### 1.1 物理环回延迟（P2，`apps/loopback --impulse --single`）

方法：播放 1 ms 脉冲（3 s 素材，脉冲旋到 0.5 s 处），USB 电容麦录回；
折叠匹配滤波定位录音里的脉冲，再用 cpal 回调时间戳把「播放回调时刻 → 采集回调时刻」相减。
单次 3 s，每组连测 5 次（`--repeat 5`）。逐脉冲极差 0 ms，检测信噪比 134–1751×。
