## 何时必须新建 ADR

- 引入任何新依赖（尤其架构级：传输/编解码/降噪/加密）；
- 改变线格式（语音包头、控制面字段）；
- 改变延迟预算中任何一行的数值来源；
- 触发执行方案 §11 的任一失败对策（A–G）；
- 关闭或延后任何 M0 闸门。
