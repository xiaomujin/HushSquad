# HushSquad（静队）

> 快如闪电，静如深海。

类 TeamSpeak 的语音开黑软件。Rust + Tauri 2，桌面与 Android 优先，Web 端暂缓。
核心追求：低延迟（分档验收）、强降噪（DeepFilterNet3 / RNNoise 双档）、频道/小队语音。
